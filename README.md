## Selected projects

### [RegAgentOps](https://github.com/bilgekayali/RegAgentOps)
An open-source reference implementation for AI-agent governance, including policy-based authorization, human oversight, delegated authority and auditable evidence.

### [FinRedOps](https://github.com/bilgekayali/finredops)
A governance-first framework for AI-assisted security assessments in regulated financial institutions. It separates AI-generated proposals from deterministic policy enforcement, explicit approvals and controlled execution boundaries.

### [ModelRiskOps](https://github.com/bilgekayali/ModelRiskOps)
A model risk governance reference architecture covering AI/ML inventory, risk classification, validation, approvals, monitoring and lifecycle evidence.

### [Energy Flex Trust Platform](https://github.com/bilgekayali/energy-flex-trust-platform)
A reference platform demonstrating secure multi-party workflows, idempotent processing, audit evidence, recovery controls and settlement integrity.
